# Sakhi Learning Trails — source of truth

1. One runtime owner per concern; no patch/override/last-rule-wins architecture.
2. Curriculum/adaptation chooses learning before any trail/theme presentation.
3. Subject trails are stable; presentation never changes skill, answer, mastery or difficulty.
4. `SakhiProgress.completeActivity()` is the one learning-evidence write path.
5. Supabase is durable authority after authentication; local storage is cache/outbox.
6. ElevenLabs narration and isolated instructional phonemes are separate paths.
7. Parent reporting derives from observable evidence; no single intelligence score.
8. `npm run qa` must pass before GitHub Pages deployment.
